  1. Look at the left sidebar
  2. Click the ⚙️ Settings icon (gear icon at the bottom)
  3. In the settings menu, click API

You'll see a section called "Project API keys" with two keys:

Step 4: Copy the Anon Key

  1. Find the anon public key (first one)
  2. Click the 📋 Copy button next to it
  3. The key is now in your clipboard
💡 How to identify it:
  • ✅ Starts with eyJ
  • ✅ Very long (200+ characters)
  • ✅ Has dots separating three parts
  • ✅ Labeled as "anon" not "service_role"

Step 5: Update Your .env File

  1. Open frontend/.env in your code editor
  2. Find the line: REACT_APP_SUPABASE_ANON_KEY=...
  3. Replace everything after the = with your copied key
  4. Should look like this:
REACT_APP_SUPABASE_URL=https://pddybafnmwkdzlqdhvra.supabase.co REACT_APP_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJzdXBh...

4. Save the file (Ctrl+S / Cmd+S)

Step 6: Restart the App

cd frontend npm start

The app will now connect to Supabase correctly! ✅

✅ How to Verify It's Working:

  1. App starts without errors
  2. You can sign up / log in
  3. Settings → Master Data shows categories
  4. You can add expenses without errors
