╔══════════════════════════════════════════════════════════════════════╗
║         HOW TO ADD "PAYMENT" CATEGORY TO SUPABASE DATABASE          ║
╚══════════════════════════════════════════════════════════════════════╝

📌 IMPORTANT: "Payment" is NOT a new table!
   It's a new CATEGORY OPTION in the existing "expenses" table.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Go to Supabase SQL Editor
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open your Supabase dashboard:
   https://supabase.com/dashboard/project/pddybafnmwkdzlqdhvra

2. Click on "SQL Editor" in the left sidebar (icon: </> or database icon)

3. Click "New Query" button (top right)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 2: Run the Payment Category Migration
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Copy and paste this SQL code into the editor:

┌────────────────────────────────────────────────────────────────────┐
│                                                                    │
│   -- Add "payment" to expense categories constraint               │
│                                                                    │
│   -- Step 1: Drop the old constraint                              │
│   ALTER TABLE public.expenses                                     │
│   DROP CONSTRAINT IF EXISTS expenses_category_check;              │
│                                                                    │
│   -- Step 2: Add new constraint with "payment" included           │
│   ALTER TABLE public.expenses                                     │
│   ADD CONSTRAINT expenses_category_check                          │
│   CHECK (category IN (                                            │
│     'labor',                                                      │
│     'material',                                                   │
│     'contractor',                                                 │
│     'transportation',                                             │
│     'payment',                                                    │
│     'food',                                                       │
│     'travel',                                                     │
│     'hotel',                                                      │
│     'equipment',                                                  │
│     'other'                                                       │
│   ));                                                             │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘

4. Click "Run" button (or press Ctrl+Enter / Cmd+Enter)

5. Wait for success message: "Success. No rows returned"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
