Step 1: Get Supabase Credentials
---------------------------------
1. Go to: https://supabase.com
2. Sign in (or create free account)
3. Create a new project:
   • Name: powermoon-construction
   • Database Password: (choose a strong password)
   • Region: (closest to you)
4. Wait 2-3 minutes for project setup
5. Go to: Settings → API
6. Copy two values:
   a) Project URL (looks like: https://abcdefgh.supabase.co)
   b) anon public key (long string starting with "eyJ...")

Step 2: Update .env File
-------------------------
1. Open: frontend/.env in your code editor

2. Replace with YOUR actual values:

REACT_APP_SUPABASE_URL=https://abcdefgh.supabase.co

   ⚠️  Replace the long "eyJ..." string with YOUR anon key

3. Save the file (Ctrl+S / Cmd+S)

Step 3: Run Database Migration
-------------------------------
1. In Supabase dashboard, click: SQL Editor
2. Open file: supabase/migration.sql
3. Copy ENTIRE file (all 880+ lines)
4. Paste into Supabase SQL Editor
5. Click: Run (or Ctrl+Enter)
6. Wait for: "Success. No rows returned"

Step 4: Run Payment Category Migration
---------------------------------------
1. In Supabase SQL Editor (same place)
2. Open file: supabase/add_payment_category.sql
3. Copy and paste into editor
4. Click: Run
5. Wait for success

Step 5: Restart the App
------------------------
cd frontend
npm start
