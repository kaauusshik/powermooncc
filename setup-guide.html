Supabase Setup Assistant

⚠️ Setup Required: Your application needs to connect to Supabase database to manage categories and other data.

Step 1: Create Supabase Project

  1. Go to https://supabase.com
  2. Click "Start your project" (or sign in if you have an account)
  3. Create a new organization (free tier is fine)
  4. Click "New Project"
  5. Fill in:
    • Name: powermoon-construction
    • Database Password: Choose a strong password (save it!)
    • Region: Select closest to your location
    • Pricing Plan: Free
  6. Click "Create new project"
  7. ⏳ Wait 2-3 minutes for setup to complete

Step 2: Get API Credentials

  1. In your Supabase project dashboard, click ⚙️ Settings (bottom left)
  2. Click API in the settings menu
  3. You'll see two values needed:
Copy from: Settings → API → Project URL
Copy from: Settings → API → Project API keys → anon public

Step 3: Save .env File

  1. After clicking "Generate .env File" above, copy the generated content
  2. Open your code editor
  3. Create a new file: frontend/.env
  4. Paste the generated content
  5. Save the file
💡 Tip: The .env file must be in the frontend/ folder, not the root folder!

Step 4: Run Database Migration

  1. In Supabase dashboard, click 🗂️ SQL Editor (left sidebar)
  2. Click "New Query"
  3. Open the file: supabase/migration.sql in your project
  4. Copy the ENTIRE file content (it's long - about 880 lines)
  5. Paste into the Supabase SQL Editor
  6. Click "Run" or press Ctrl+Enter
  7. Wait for "Success. No rows returned" message
  8. This creates all database tables, including category tables
✅ What this does:
  • Creates all database tables
  • Sets up Row Level Security (RLS) policies
  • Adds 8 default work categories
  • Adds 10 material categories
  • Adds 16 default materials

Step 5: Start the Application

cd frontend
npm start

The app will open at http://localhost:3000

Step 6: Test Categories

  1. Sign Up: Create your account (first user becomes Owner automatically)
  2. Login: Sign in with your credentials
  3. Go to Settings: Click Settings in the navigation menu
  4. Open Master Data: Click the "Master Data" tab
  5. You should now see:
    • ✅ Work Categories (with 8 default categories)
    • ✅ Material Categories (with 10 default categories)
    • ✅ Clients section (empty initially)
  6. Test Adding: Click "+ Add" next to any category section
  7. Enter a name and click Save
  8. The new category should appear immediately!
